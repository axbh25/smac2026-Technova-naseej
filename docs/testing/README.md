# Naseej Testing Evidence

This folder contains manual test records, automated-test summaries, device
information, and selected screenshots that demonstrate gradual application
quality.

## Rules

1. Record only tests that were actually performed.
2. Include the exact device or emulator used.
3. Record failures as well as passes.
4. Do not edit screenshots to hide application defects.
5. Never include passwords, tokens, private notifications, or real family data.
6. Keep screenshots organized by development day or milestone.

## Reference Device

- Emulator: Pixel 7 Pro
- Android API: 36
- Figma viewport: 412 × 892 logical pixels
- Orientation: Portrait
