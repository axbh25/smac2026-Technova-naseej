## Data Handling

Naseej stores:

- One private local photo file
- The private photo path inside the local SkillDraft

Naseej does not:

- Upload the photo
- Share the photo publicly
- Store the photo in GitHub
- Send the photo to AI in the MVP
- Store a public gallery copy

## Design Decisions

1. A context photo is optional.
2. Only one photo is allowed.
3. Images are resized during selection.
4. Camera-cache paths are never persisted directly.
5. Images are copied into application-support storage.
6. The photo picker uses the Android system picker where available.
7. No broad storage permission is requested.
8. Existing text and speech features remain usable without a photo.
9. Image AI analysis is deferred.
