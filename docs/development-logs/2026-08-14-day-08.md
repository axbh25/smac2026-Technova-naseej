## Runtime AI Data Not Sent

- Stored teacher nickname
- Stored learner nickname
- Context photo
- Photo path
- Location
- Contacts

A name typed manually inside the reviewed explanation is part of the reviewed
text and is sent unless the user removes it.

## Design Decisions

1. The user explicitly starts generation.
2. Structured JSON guides model output.
3. Runtime validation remains mandatory.
4. Exactly three steps are required.
5. The context photo remains local.
6. AI content is previewed before saving.
7. Cloud failure creates a visibly labeled Offline Guide.
8. Editing the source draft invalidates the old card.
9. Only one saved card is included in the MVP.
10. Individual generated-step editing is deferred.
