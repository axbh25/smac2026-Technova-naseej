- Profile role

No account, location, photo, recording, or cloud data is stored.

## Design Decisions

1. Profile data remains on the phone.
2. `SharedPreferencesAsync` stores only small, non-critical settings.
3. Future completed skill exchanges will require more suitable structured
   storage.
4. One local profile is sufficient for the Day 3 vertical slice.
5. The Home action buttons provide honest temporary feedback.
6. The application restores directly to Home after profile creation.
