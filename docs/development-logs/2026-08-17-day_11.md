## Design Decisions

1. Lesson completion was required before the Family Thread appeared.
2. The reciprocal suggestion could be copied but remained editable.
3. A return skill required 3–220 characters.
4. Family Thread completion required explicit user action.
5. Editing the return skill invalidated Family Thread completion.
6. Editing the teach-back response invalidated both completion levels.
7. Unchecking a step invalidated both completion levels.
8. Older Day 9 progress remained compatible.
9. No new storage key was added.
10. No cloud request was added.
