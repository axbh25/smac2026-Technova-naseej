## Data Handling

Naseej stores:

- Recognized or manually typed text inside the local SkillDraft

Naseej does not store:

- An audio file
- Raw microphone data
- A cloud speech transcript
- Voice biometric data

The Android speech service may process speech through a remote service.

## Design Decisions

1. Voice input is optional.
2. Manual typing always remains available.
3. The user must review and may edit recognized text.
4. Recognition is short and user-initiated.
5. There is no continuous or background listening.
6. Language switching is disabled while actively listening.
7. Bluetooth headset support is excluded from the MVP.
8. Voice recognition is not claimed to be offline.
