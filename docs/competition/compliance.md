## Mobile Requirement

Naseej must be delivered as an installable mobile application, not a web-only
application.

Target deliverable: Android APK.

## AI-Assisted Development

AI may support:

- Planning
- Concept explanations
- Wording drafts
- Small isolated code assistance
- Debugging explanations
- Test suggestions

AI may not:

- Generate the complete application
- Generate entire features that the developer cannot explain
- Hide its contribution
- Copy complete project parts from another source

Every meaningful prompt and contribution is documented under `docs/ai-usage/`.

## GitHub Evidence

The repository will show:

- Regular development activity
- Small meaningful commits
- Organized project structure
- README documentation
- Development logs
- Test evidence
- AI-use records
- Honest participant contributions
