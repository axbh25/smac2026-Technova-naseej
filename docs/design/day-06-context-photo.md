# Naseej Day 6 Context Photo

## Reference Device

- Pixel 7 Pro
- Android API 36
- 412 × 892 logical pixels
- Portrait orientation

## Approved Frames

- `09_TeachPhotoEmpty_EN`
- `10_TeachPhotoSelected_EN`
- `11_HomePhotoDraft_EN`
- `09_TeachPhotoEmpty_AR`
- `10_TeachPhotoSelected_AR`
- `11_HomePhotoDraft_AR`

## Context Photo Card

- Width: 364
- Empty minimum height: 156
- Selected preview height: 180
- Padding: 16
- Corner radius: 16
- Preview radius: 12
- Action height: 56

## States

- Empty
- Selected
- Busy
- Error
- Missing saved file

## Behavior

1. Tap Add Context Photo.
2. Choose Camera or Gallery.
3. Cancel safely or select one image.
4. Copy the image into private app storage.
5. Display a preview.
6. Replace or remove it.
7. Save the draft.
8. Restore the image after restarting the application.

## Privacy

- One photo only
- Photo remains in private local application storage
- Photo is not uploaded
- Photo is not sent to the runtime AI service in the MVP
- No public sharing

## Deferred

- Multiple images
- Image cropping
- Image filters
- Video
- Cloud backup
- Image AI analysis
