## Family Thread Rules

1. The learner must complete the lesson first.
2. Lesson completion still requires all three steps.
3. Lesson completion still requires a valid teach-back response.
4. The return skill accepts 3–220 characters.
5. The reciprocal suggestion may be copied but remains editable.
6. The Family Thread is completed only after explicit user action.
7. The return skill and completion timestamp are stored locally.
8. Editing the lesson invalidates Family Thread completion.
9. Editing the return skill invalidates Family Thread completion.
10. Older saved progress remains compatible.

## Data Boundary

Day 11 makes no Firebase AI request.

The following remains local:

- Completed step indexes
- Teach-back response
- Return-skill response
- Lesson completion timestamp
- Family Thread completion timestamp
- SkillCard fingerprint

## Accessibility

- All actions include icons and labels
- Touch targets are at least 48 logical pixels
- Long text wraps
- Screen remains vertically scrollable
- Arabic uses RTL
- The user may complete the lesson without completing the reciprocal thread
